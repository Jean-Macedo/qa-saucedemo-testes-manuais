# Bugs

Os bugs são registrados como **Issues no GitHub**, usando o modelo "Bug report"
(aba Issues > New issue). Esta tabela é o índice.

## Como registrar

1. Abra uma Issue com o modelo "Bug report".
2. Use o título no padrão `[BUG-001] [Módulo] Resumo do problema`.
3. Arraste o print ou vídeo para o campo Evidência.
4. Adicione uma linha na tabela abaixo com o link da Issue.

A numeração BUG-001, BUG-002... é sequencial e é a mesma usada na planilha de execução.

## Ciclo de vida

```
Novo -> Em análise -> Em correção -> Pronto para reteste -> Fechado
                  \-> Rejeitado (não é bug / duplicado)
```
