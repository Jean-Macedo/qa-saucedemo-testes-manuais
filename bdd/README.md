# Cenários BDD

Cenários em Gherkin (pt-BR) para os fluxos principais. Servem para alinhar o comportamento
esperado com o time antes do desenvolvimento e como base para a automação.

As tags (`@CT-LOG-001`) ligam cada cenário ao caso de teste correspondente.
A tag `@smoke` marca o teste rápido de sanidade, que roda antes de qualquer outro.
