# Evidências

Prints e vídeos da execução. Toda falha tem evidência. Nos casos que passam, é opcional.

## Padrão de nome

`<ID-do-caso>_<usuário>_<status><DDMMAAAA>.png`

Exemplos:
- `CT-SES-004_standard_user_falhou24092026.png`
- `CT-CAT-001_problem_user_falhou24092026.png`
- `CT-CHK-005_error_user_falhou24092026.png`

Todos os prints ficam direto nesta pasta, tanto do ciclo principal quanto da regressão.
O usuário no nome indica de qual perfil é cada evidência.
